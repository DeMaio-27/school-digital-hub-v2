# School Digital Hub v2

Piattaforma scolastica con ruoli, dashboard e backend PHP/MySQL.

## Struttura

- `index.html`: landing page
- `login.html`: accesso utenti
- `dashboard.html`: demo frontend
- `backend/`: PHP e database MySQL

## Avvio locale

1. Copia la cartella in `xampp/htdocs/`
2. Avvia Apache e MySQL da XAMPP
3. Importa `backend/database/schema.sql` in phpMyAdmin
4. Modifica se necessario `backend/db.php`
5. Apri `http://localhost/school-digital-hub-v2/`

## Tecnologie

HTML, CSS, JavaScript, PHP, MySQL/MariaDB.
