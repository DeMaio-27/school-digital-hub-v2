# School Digital Hub v2

MVP scolastico PHP/MySQL modulare.

## Avvio locale
1. Copia la repo in `xampp/htdocs/`.
2. Avvia Apache e MySQL.
3. Importa `backend/database/schema.sql` in phpMyAdmin. **Attenzione: ricrea il database**.
4. Apri una sola volta `http://localhost/school-digital-hub-v2/backend/database/seed_users.php`.
5. Rinomina o elimina `seed_users.php`.
6. Apri `http://localhost/school-digital-hub-v2/login.php`.
